# Cognitive Layer identity

Outlined SVG masters from the September 2026 brand pack. Use `logo-dark.svg` / `mark-dark.svg` on black and the light versions on white. The web viewBoxes remove export padding; preserve clear space of at least one quarter of the icon width in the layout.

Palette: Ink #101C32, Cobalt #3155D9, Layer blue #537DF5, Signal mint #62D8CC, white #FFFFFF and black #000000. Do not change plane opacity, geometry, or wordmark proportions. The favicon uses the simplified solid mark to preserve legibility at small sizes.

Inter is self-hosted in `assets/fonts`; its SIL Open Font License is included there. Use Regular for copy, Medium for headings and Semibold for controls. Logo lettering is outlined and does not depend on the font loading.
